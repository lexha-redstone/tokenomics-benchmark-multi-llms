🏛️ Architectural Mechanics & Empirical Advantages

Smart Tiered Cascade

2-Tier Flow
Dispatches initial drafting to gemini-3.5-flash-lite ($0.30 / $2.50 per 1M). Simple tasks succeed immediately at sub-cent spend (~$0.001). Only upon failure does Straitjacket harness escalate with exact stack trace to gemini-3.7-flash thinking model.
Key Benefit: Slashes Cost per Solved task by 2.15x on BigCodeBench-Hard while improving pass rate to 26.0%.

Straitjacket Smart Repair

Advisor-Executor
gemini-3.7-flash acts as an architect generating a strict <200-word contract specification. gemini-3.5-flash-lite writes the implementation. On test failure, Straitjacket triage routes the exact assertion error to 3.7-Flash for surgical repair.
Key Benefit: Lowest cost per solved task in WebDev suite at $0.0313/task (2.13x cheaper than Claude Sonnet-5).

Dual-Candidate Consensus

Parallel Diff
Generates two independent low-cost candidate implementations in parallel with 3.5-Lite, diffs their runtime failure signatures deterministically using ctx diff, and feeds the comparative delta to 3.7-Flash for high-confidence resolution.
Key Benefit: Tied for highest pass rate on both benchmarks (26.0% BCB, 44.0% WebDev) while maintaining 2.21x cost efficiency.
